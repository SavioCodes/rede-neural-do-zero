# Support

## Onde comecar

Antes de abrir issue, passe por esta ordem:

1. [README.md](./README.md)
2. [Docs publicadas](https://saviocodes.github.io/rede-neural-do-zero/)
3. [Wiki](https://github.com/SavioCodes/rede-neural-do-zero/wiki)
4. [FAQ](./docs/faq.md)
5. [CLI](./docs/cli.md)

## Quando usar Issues

Use a aba de issues para:

- bugs reproduziveis
- pedidos de melhoria bem definidos
- duvidas que dependem de contexto do projeto
- problemas de documentacao

## Quando nao usar Issues

- vulnerabilidades com detalhes sensiveis
- logs contendo segredos
- perguntas que ja estao respondidas nas docs principais

Para vulnerabilidades, siga [SECURITY.md](./SECURITY.md).

## Como pedir ajuda melhor

Inclua:

- comando executado
- dataset ou config usada
- erro completo
- comportamento esperado
- sistema operacional e versao do Python

# Roadmaps por Versao

Esta pasta concentra o fluxo oficial de planejamento por versao do projeto.

Cada arquivo versionado deve responder quatro perguntas:

1. qual e o objetivo da versao
2. o que precisa ser entregue antes da release
3. quais links oficiais acompanham issues, PRs e release
4. qual checklist precisa ficar verde antes de tag/release

## Como usar

1. copie o [template oficial](./template.md)
2. crie o arquivo da proxima versao, por exemplo `v2.6.0.md`
3. preencha objetivo, checklist, entregaveis e links
4. atualize o [ROADMAP.md](../ROADMAP.md) com o estado da versao
5. mantenha PRs, issues e release notes alinhados com o arquivo da versao

# Referencia de API

Esta secao documenta a interface publica principal do projeto usando geracao automatica a partir do codigo-fonte.

Ela acompanha a organizacao interna atual do projeto:

- `src.core`
- `src.training`
- `src.data`
- `src.workflows`
- `src.interfaces`

## O que voce encontra aqui

- a classe `RedeNeural`
- configuracoes declarativas do modelo e do treino
- callbacks oficiais
- helpers de datasets, metricas e visualizacao
- funcoes de benchmark e avaliacao
